JUMBO BUILDERS WEBSITE — VISUAL STUDIO CODE

FILES
- index.html: website content and structure
- style.css: responsive layout and design
- script.js: mobile menu and quote form behaviour

HOW TO RUN
1. Extract this ZIP file into a folder.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select the extracted folder.
4. Open index.html.
5. Recommended: install the Live Server extension, right-click index.html and select “Open with Live Server”. You can also open index.html directly in a browser.
